# Fisica 1

Resumen teorico y ejercicios de la asignatura Fisica 1, FING, UdelaR.

## Organizacion

El repositorio esta organizado en carpetas, cada una correspondiente a un tema de la asignatura. Dentro de cada carpeta se encuentran los archivos correspondientes a la teoria y ejercicios de cada tema.

Generlamente se sigue el siguiente formato:

```
temas/
│   tema_n/
│   │   nombre_tema.md
practicos/
│   tema_n/
│   │   p1.pdf
│   │   p1_ej1.ipynb
recursos/
│   libro.pdf
```
